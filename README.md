# Flashix Tool
Flashix is a ISO flasher that Claude 4.5 Sonnet created and I continue to update the package list. It downloads ISOs and flashes in one go. You will not need to update your app for un update unless the release/tag says so - most updates are only of the .xml. Even so, the XML still usually can update to newer versions if you are on an old version of the app. All you need is `python3`, `tkinter`, and `requests` installed. Then you just run the python file.

To try experimental multi-boot functions, run the python script with the `--multi` flag.
